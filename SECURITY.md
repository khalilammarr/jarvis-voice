# Security

Jarvis can run shell commands by voice, so its safety model matters. See
[docs/privacy-and-safety.md](docs/privacy-and-safety.md) for what it protects and what it does not.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting ("Security" tab, "Report a vulnerability")
instead of a public issue. Include steps to reproduce. Bypasses of the command guard, the
deny-path filter or the secret scrubber are in scope.

Never include real API keys in a report.
